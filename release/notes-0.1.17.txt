本次更新：

- 預設啟用開機啟動，可在設定中同時取消主程式與背景服務的自動啟動；保留既有取消偏好。
- 開啟「檢查更新」即查詢最新發布版本，不需再按一次。
- 改善多組線路匯入，清單先顯示，再於背景檢測；保留到期時間。
- 最多 5 條線路並行優先檢測 TCP，先顯示實際 IP 與入口連線延遲，UDP 與所在地另在背景補測。
- 「立即檢測」有選取時只測選取線路，未選取時測全部；背景補測結束後顯示「檢測完成」。成功約 30 分鐘複測、失敗約 5 分鐘重試。
- 預設建立桌面捷徑，設定提供工作列釘選入口；實際釘選依 Windows 支援及授權。
- 減少重複規則更新與無模擬器時的探索等待，保留原有代理與遠端控制直連設定。

提供自帶 .NET 的 Windows x64 可攜 ZIP 與安裝 EXE。可從舊版「設定 → 檢查更新」手動升級；更新已安裝背景服務時需要 Windows 管理員授權，代理連線會短暫中斷，既有設定保留。
