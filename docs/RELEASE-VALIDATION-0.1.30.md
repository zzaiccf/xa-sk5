# xa sk5 0.1.30 驗證範圍

日期：2026-10-30。Windows x64，本機驗證；未將私人代理、遊戲檔案、帳號或診斷資料放入發布包。

## 已通過

- 管理程式核心回歸 **383／383**，包含設定寫入失敗／取消回復、繼承值排除、固定裝置映射、啟動間隔、去重、同時啟動阻擋、取消保留已啟動實例，以及慢速探索不阻塞快照。
- 原生封包路徑 **157,339** 項斷言；不開啟擷取控制代碼。包含活躍連線並行計時及送出錯誤的既有回歸。
- WPF 規則頁在主工作佇列與探索均被合成測試阻塞時，開窗約 **186 ms**；沙盒工作等待時 dispatcher 回應約 **51–62 ms**。冷啟動的整個 WPF 沙盒視窗約 **1.1 秒**，不宣稱所有電腦或所有視窗均低於 200 ms。
- 沙盒介面固定 A／B 線路、取消後恢復控制、手動相容選擇不被背景辨識覆蓋、批量倒數取消、右鍵選定 B 啟動正確實例，以及程序清單背景載入。一般與最小視窗尺寸已檢視，長內容可捲動，進度固定在底部。
- 使用實際 Sandboxie Plus 1.18.8 建立兩個全新合成遊戲沙盒，逐一核對 32 個網卡映射與磁碟識別，不同實例不同、重複套用保持固定。確認設定檔持久寫入、reload 後讀回及再次準備保留副本更新。測試未執行合成遊戲。
- 最終可攜包 **354 個檔案**的 SHA-256 與組件版本核對通過；單檔安裝程式內嵌套件核對通過。
- 真正更新程式完成 **0.1.29 → 0.1.30** 的獨立可攜目錄更新，保留合成使用者設定並產生可回復備份；此檢查未變更使用中的背景服務。

## 遊戲相容性與限制

此前 0.1.29 曾完成 YongOrigin 兩個不同帳號登入並進入角色，以及至少 30 分鐘觀察；期間未見核心重啟或 A／B 換線。這是同機同一遊戲版本的證據，不是所有玩家與遊戲版本的保證。

本次 0.1.30 驗收重點為引導準備、相容設定保存、佇列、介面與背景探索；沒有重新執行完整 30 分鐘雙帳號遊玩。遊戲更新器「Download failed」仍須依遊戲本身提供的繼續按鈕處理，不視為已完成遊戲登入。

共享 Windows DNS、實際受管 IPv6、服務／驅動崩潰時的完整隔離未作全面保證；不以主機探測代替每個沙盒內的出口核驗。新引導準備需 0.1.30 背景服務及完整核心；更新服務前應正常關閉受管遊戲。
