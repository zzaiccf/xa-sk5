# 0.1.35 測試版：另一台電腦驗收清單

這份清單由使用者在另一台電腦操作，尚未執行。0.1.35 是測試包，不是 GitHub 正式發布；先保留 0.1.32 安裝包及既有備份。不要把帳號、密碼、代理認證或 settings.dpapi 傳回。

**任何一步失敗：先到「設定 → 匯出診斷」，記下當地日期、時間、版本及剛才操作，保留檔案，再停止後續測試。** 無法匯出時，先保存錯誤畫面及服務日誌，說明匯出失敗的原因；不要反覆重裝或刪除實例。

## 1. 從 0.1.32 升級

- [ ] 在「設定 → 技術資訊」記下目前介面與背景服務版本。確認來源是正式版 0.1.32。
- [ ] 正常登出並關閉遊戲，保存設定備份，再正常退出舊介面。安裝會更新背景服務，請先結束需維持的連線。
- [ ] 對照隨包 `SHA256SUMS.txt`，使用 `Get-FileHash -Algorithm SHA256 .\xa-sk5-Setup-0.1.35.exe` 核對雜湊。
- [ ] 執行 `xa-sk5-Setup-0.1.35.exe`，自行確認 UAC 與安裝精靈。不要同時開著另一資料夾內的舊版介面。
- [ ] 開啟已安裝的 xa sk5，核對介面及背景服務都是 **0.1.35**。既有規則、實例與固定線路應保留，不應被重新分配。
- [ ] 等待「正在建立 WFP 防護」完成，記錄大約等待幾秒；未完成或出錯時先匯出診斷，不繼續啟動遊戲。

若需回復，先正常關閉遊戲、匯出診斷並保存設定與安裝紀錄，停止測試並回報，再依確認的回復流程處理。安裝包有防降版檢查，不要強行用舊版覆蓋，也不要自行清空設定、移除 Sandboxie 或刪除遊戲副本。

## 2. 規則管理的右鍵選單

- [ ] 單選沙盒 A：有「啟動此實例」「停止此實例」；編輯／移除可用。啟動處會說明開啟的是遊戲啟動器。
- [ ] 用 Ctrl 選 A、B，或用 Shift 選連續數列：顯示「啟動選取的 2 個實例（間隔 10 秒）」「停止選取的 2 個實例」；編輯／移除不可用。選更多列時數字應相符。
- [ ] 在已選取的 A 或 B 上按右鍵：保留原來多選，不縮成一列。
- [ ] 在原選取範圍外的另一列按右鍵：改成只選那一列。
- [ ] 同時選沙盒及一般規則：不顯示啟動／停止，不能編輯或移除多列。
- [ ] 不再出現「啟動此遊戲全部實例」。工具列顯示「啟動全部沙盒（間隔 10 秒）」，此工具列功能仍會處理全部沙盒。

## 3. 先開 A，再選 A＋B

- [ ] 單選 A，右鍵啟動。應開啟 A 的遊戲啟動器；YongOrigin 請自行按「開始遊戲」並登入。
- [ ] 保持 A 執行，Ctrl 選 A、B，右鍵啟動選取的兩個實例。
- [ ] A 應顯示 **「已在執行，略過」**，不多開一個 A，也不把原 A 暫停。
- [ ] B 應開啟啟動器，顯示 **「已開啟啟動器，請在啟動器按開始遊戲並登入」**；自行繼續開啟與登入。依表格當時顯示的順序處理，需新啟動的項目依設定間隔執行。
- [ ] 記錄每個實例從按啟動到開出啟動器的時間，以及 A 是否持續可操作。此程式不自動按遊戲按鈕或自動登入。

## 4. 保存／準備與 SBIE1402

- [ ] 先正常停止要重新保存的遊戲實例，再操作「準備環境／保存」。已存在且沒有變更的設定不應重複寫入。
- [ ] 若顯示「設定待初始化」，仍應可按準備環境，由官方工具建立設定；不應卡在「無法備份」。
- [ ] 若出現 **SBIE1402**，先記下準確時間與時區、訊息全文及當時操作，並先匯出診斷。
- [ ] 帶回該實例的 **`ConfigBackups\commands-*.jsonl`**，包含出錯前後的紀錄。預設位於 `%USERPROFILE%\WindowSocksGames\SandboxGames\<實例ID>\ConfigBackups`；請由儲存空間清單核對該實例的實際資料夾。
- [ ] 如有啟動錯誤，另保留該盒的 `sandbox-bootstrap-error.txt`、`sandbox-monitor-error.txt`。預設在上述實例的 `Box\user\current\AppData\Local\WindowSocks`，映射不同時可能在 `Box\drive`；找不到請回報，不要任意刪除沙盒。先遮蔽個人資料與認證。

## 本次未授權執行的測試

**NOT RUN**：從未安裝 Sandboxie 的乾淨電腦／可回復 VMware 快照，測試自動安裝 → 等待服務就緒 → 準備 → 啟動。必須另外取得使用者同意才執行，不能以已有 Sandboxie 的電腦升級成功代替。

真實遊戲多開、0.1.33 移除功能實機驗收、0.1.31 C1／C2／C4／C6 仍為 NOT RUN；C5 外側 FIN／RST 擷取保持 NOT RUN。不要為測五分鐘 helper 退出而在正式遊戲連線中強停服務。

回報可用：`步驟／PASS 或 FAIL／時間與時區／介面及服務版本／看到的訊息／診斷檔名`。登入資料由使用者保管。
