# xa sk5 0.1.24 驗證範圍

2026-10-24，Windows x64。此版加入全局代理時長及視窗縮小／退出操作。

## 已完成的回歸

- 核心／服務／更新器測試 337 項通過，無略過。包含全局計時的持續使用、換線、受阻後恢復、服務重啟、JSON 往返、跨日顯示、時鐘回撥、離線及舊服務相容。
- 隔離 WPF 計時測試：沿用服務起始時間，每秒更新且零額外 RPC；最小 1040×650 與一般視窗版面可顯示跨日時長。封鎖、恢復、離線及缺少起始時間的狀態符合預期。
- 隔離 WPF 退出測試：X／最小化保留代理、短暫通知及去重、系統匣還原、工作列退出指令與含空白路徑、等待服務停止、停止失敗重試、啟動途中退出及更新器交接。
- 規則添加頁與批次操作 WPF 回歸通過。
- 原生安裝器前置視窗的延遲啟動、交接、暫存清理、啟動失敗回報及無介面驗證通過。

測試入口為 `Test-GlobalDuration.ps1`、`Test-TrayBehavior.ps1`、`Test-RuleEditorPerformance.ps1`、`Test-BulkActionsUi.ps1` 與 `Test-SetupBootstrap.ps1`。介面測試使用合成資料與假服務，不調整本機實際全局代理、遊戲或節點。

## 套件發布門檻

主要元件版本、完整套件每檔 SHA-256、官方 WinDivert 驅動簽章及最終安裝器內嵌套件均須通過驗證。另以隔離副本從 0.1.23 執行實際更新工作程序，核對合成設定保留與更新後完整性。GitHub 僅上傳安裝 EXE 及完整可攜 ZIP，公開前核對遠端大小與 SHA-256。

## 操作與限制

時長是全局代理政策本次生效的時間，由背景服務記錄，並非遊戲登入或單一 TCP 連線時長。既有健康寬限期間仍使用同一次代理時長；實際轉為封鎖後清除。重新開啟介面接續原起始時間，背景服務或核心重啟後重新計時。請一併更新背景服務至 0.1.24；舊服務顯示「待服務提供」。Windows 通知的實際顯示時間依系統設定。

本版沒有新增遊戲登入後或長時間遊玩驗收。既有網路封包路徑驗證與遊戲限制見 [0.1.23 驗證範圍](RELEASE-VALIDATION-0.1.23.md)。
