# xa sk5 0.1.24

繁體中文 Windows x64 SOCKS5 代理工具，提供程序／子程序分流、模擬器配置、全局代理、節點檢測及 Windows 背景服務。

這是工程預覽版。普通 Windows 程序的真實 TCP／UDP／DNS 轉送及程序接續已驗證；個別遊戲、模擬器與虛擬機仍須分別驗收。

## 0.1.24 更新

- 全局代理狀態卡加入「代理時長」，支援天數及時分秒。背景服務確認核心執行且節點可用後開始計時；停用、換線、核心重啟或線路受阻後重算，重新開啟介面接續原時間。服務斷線顯示「未確認」，舊服務沒有計時資料時顯示「待服務提供」。
- 按 X、Alt+F4 或工作列「關閉視窗」縮小至工作列，代理維持運作。最小化及按 X 時要求 Windows 顯示短暫提示，同次縮小不重複通知。
- 工作列及系統匣右鍵加入「退出」。等待背景服務停止才結束，停止失敗還原介面供重試，並處理啟動途中退出的交接。

## 0.1.23 更新

- 修正啟用「涵蓋子程序」時反覆列舉全機程序，造成主機其他連線延遲、丟包或逾時。封包路徑改用單一程序物件的父系查詢，保留 PID＋建立時間、Job Object、交接及暫停封鎖。
- 規則管理的添加頁立即開窗，探索與網路清單移至背景，保留取消、儲存及舊服務能力檢查。
- 「代理與檢測」加入「清除所有 IP」。有窗口、固定配置或啟用中的全局代理使用節點時，整批拒絕並提示先解除使用。
- 「窗口列表 → 更多」加入「關閉所有代理進程」。確認範圍後結束個別綁定的程式與子程序，保留全局代理、節點及規則；執行前再次核對程序身分與擁有者。
- 一般程序路徑／檔名規則接續登入器啟動的子程序。相同程序樹保留 IP，明確解除、暫停及規則變更仍立即生效。
- 改善更新工作交接、取消與服務狀態恢復；先停止代理再下載，完整性驗證及備份完成後替換程式，保留既有設定。
- 新增每秒核心處理、佇列與錯誤計數；8 MiB 換檔並保留最近 16 份，不記錄封包內容或帳密。

## 下載與安裝

發布頁只提供兩個附件：

- `xa-sk5-Setup-0.1.24.exe`：安裝精靈、背景服務、捷徑與解除安裝項目；由 Windows 要求管理員授權。
- `xa-sk5-0.1.24-win-x64.zip`：自帶 .NET 的完整可攜版。解壓全部檔案後執行 `xa sk5.exe`，保留同一資料夾內的 DLL。

官方 WinDivert 2.2.2 x64 DLL／SYS 配對檔案包含於發布套件，建置時驗證 SYS 簽章。程式及安裝包目前沒有發布者程式碼簽章；SHA-256 完整性驗證不取代發布者簽章。

已安裝使用者可到「設定 → 檢查更新」，確認版本後按「升級」。不定時自動查詢或自動安裝。更新背景服務會中斷現有代理連線，遊戲可能需要重新連線；原有代理、到期日、綁定及配置保留。0.1.15 或更早版本建議先手動使用完整安裝包更新一次。

## 使用方式

1. 在「代理與檢測」匯入 SOCKS5 節點，確認實際 TCP／UDP 檢測結果。
2. 在「窗口列表」分配正在執行的程序，或在「規則管理」建立路徑、檔名、模擬器或 VMware 規則。
3. 需要一般程序接續時啟用「接續遊戲與子程序」；每一棵可確認來源的程序樹為一組。同一 PID 內的多個視窗共用網路身分。
4. 從實際窗口驗證出口 IP。節點檢測的出口與後台流量計數不能代替窗口內的獨立驗證。

支援匯入 `host:port`、`host:port:user:password`、SOCKS5 URI 及 CSV；代理憑證以原 Windows 帳戶／機器的 DPAPI 設定範圍保存。雷電與 MuMu 提供固定編號或依啟動順序分配；VMware 提供專用主機端 IPv4 網路配置與備份恢復流程。

全局代理提供區網及遠端控制程式直連選項，指定程序與暫停政策仍優先。啟用中的全局代理在各頁面顯示狀態；服務斷線或檢測失敗會顯示原因。

關閉主視窗與最小化維持代理運作；從工作列或系統匣右鍵選「退出」才會停止代理並結束程式。開機啟動偏好可在設定頁取消，更新不會重新勾選已取消的設定。

## 驗證與限制

0.1.23 已完成核心回歸、原生封包路徑測試及真實 WinDivert 服務開／關對照。啟用子程序規則的對照中，每階段 120 次 ICMP／TCP 零失敗；服務中主機 RTT 平均約 7.55 ms。真實普通子程序的 TCP／UDP／DNS、登入器退出接續、暫停與恢復已驗證。

特定遊戲已能進入空白帳密頁，但觀察到未登入約三分鐘後上游 EOF；不同協定狀態的被動直連／SOCKS 對照不足以判定原因。登入後遊玩、各遊戲允許的多開方式、雙雷電／雙 VMware 實機及長時間穩定性仍須驗收。詳見 [版本驗證範圍](docs/RELEASE-VALIDATION-0.1.23.md)。

支援範圍為 Windows IPv4 TCP／UDP。受管 IPv6、無法確認身分或來源歧義採保守處理；Windows 共享 DNS、獨立系統服務啟動的程序及橋接網路有額外限制。沒有持久 WFP kill switch，服務／驅動異常不能當作防洩漏保證，也不保證與所有遊戲保護程式相容。

## 建置與測試

需求：Windows x64、PowerShell 7、.NET 10 SDK、Visual Studio C++ x64 工具及 Windows SDK。

```powershell
./scripts/Build.ps1 -PayloadDirectory artifacts/local
./scripts/Test-PacketPathPerformance.ps1
./scripts/Test-RuleEditorPerformance.ps1
./scripts/Test-BulkActionsUi.ps1
./scripts/Test-TrayBehavior.ps1
./scripts/Test-GlobalDuration.ps1
```

本機建置不會發布。官方 WinDivert 二進位快取置於 `third_party/WinDivert-2.2.2-A/x64`，不納入原始碼；建置不自動下載驅動或更改安全性設定。需要發布時依 [RELEASING.md](docs/RELEASING.md) 建立完整套件、測試更新器，再上傳草稿並公開。

`Directory.Build.props` 是版本唯一來源。主要程式碼位於 `src/`、`native/`，測試位於 `tests/`；使用者設定、私人測試紀錄及建置產物不納入發行資產。
